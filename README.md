# Customer-Intelligence-Analytics-System


## Overview

Customer Intelligence &  Analytics System is an end-to-end business analytics project developed using MySQL and Python. The project demonstrates how structured business data can be transformed into actionable insights through SQL-based analysis and Python integration.

The solution covers customer analysis, sales performance, product performance, order operations, payment analytics, and customer feedback analysis using a relational database consisting of multiple interconnected tables.

---

## Objectives

- Analyze customer purchasing behaviour.
- Evaluate sales and revenue performance.
- Measure product performance across categories.
- Monitor order and payment operations.
- Analyze customer feedback and product ratings.
- Integrate Python with MySQL for automated query execution.
